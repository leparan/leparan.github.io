## Run it locally

No build step is needed. Download `index.html` and open it in any web browser.

## Publish it with GitHub Pages

1. Create a public repository named `<your-username>.github.io`.
2. Upload `index.html` to the repository root and commit.
3. In the repository (not your account), open **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose `main` and `/ (root)`, and save.
5. After a minute or two, the site is live at `https://<your-username>.github.io`.

## Update the content

Edit `index.html` directly on GitHub (open the file, click the pencil icon, then **Commit changes**) or upload a replacement file. GitHub Pages republishes automatically.
